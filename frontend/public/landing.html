How does the recommendation engine work?
SF
The recommendation engine uses a MedicineRecommender class that takes patient symptoms, translates them via Google Translate, and runs them through a scikit-learn ML pipeline.
The core logic lives in:
ml_model.py:11-489 views.py:76-119
The recommend() view handles form submission, calls translate_hindi_symptoms(), then passes results to the ML model.
What database models does this project define?
SF
Two Django models are defined in models.py:5-32:
MedicineData — stores medicine names, categories, symptoms, and side effects for the recommendation dataset.
PatientQuery — records each user's symptom query, age, gender, and the AI-generated recommendations as JSON.
